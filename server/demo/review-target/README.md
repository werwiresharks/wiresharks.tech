# Demo review target

A tiny, deliberately flawed sample repository. It is **not** part of the
service — it is the input the live console reviews, so `/console` shows a real
Raptor review (real scanner, real Prove step, real events) over a small,
legible codebase instead of a hand-written script.

Each file plants one well-known defect class so the review has something to
map, find, and rule on. Nothing here is executed.
